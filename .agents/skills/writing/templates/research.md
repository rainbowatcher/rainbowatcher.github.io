## 问题

触发场景一句话：为什么现在要答这件事，不答会怎样。

## 候选

| 方案 | 成本 | 风险 | 现状   |
| ---- | ---- | ---- | ------ |
| A    |      |      | 未验证 |
| B    |      |      | 未验证 |

## 当前判断

能确定的一句。不能确定的写 `未验证`，不要给模糊结论，也不要把两个方案并列当结论。

## 下一步

- 可粘贴的验证命令，以及判据：成功 = 什么输出、失败 = 什么现象。
- 决定去留的条件：什么情况下放弃这个方向。
