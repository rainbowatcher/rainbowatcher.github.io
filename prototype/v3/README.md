# UI 重构 · 交互原型 v3

把站点当成**个人知识库**来排版的一版原型：除了博文，还展示项目、在用工具、
研究 / 踩坑内容与归档。它不接入 Nuxt 构建，也不改动现有页面，只用来确认视觉方向、
信息层级与阅读交互。

## 运行

原型不加载任何 web font：中文走系统字体，标题走系统衬线，代码走系统等宽。
从仓库根目录起一个静态服务（ES module 需要 http）：

```bash
python3 -m http.server 4173 --directory .
```

打开 <http://localhost:4173/prototype/v3/>。

## 设计取向

- **淡色纸面。** 亮色主题以 `hsl(200 32% 97%)` 为底，墨色是 `hsl(203 34% 21%)`；
  暗色主题以 `hsl(203 60% 12%)` 为主色，字面用 `hsl(198 26% 86%)`。两套主题都用
  有彩底与有彩字，正文与底色保持约 11:1 的可读比值，但**没有纯黑、纯白的大色块，
  也没有从黑封面翻到白纸的明暗跳变**。
- **彩虹只做点缀。** 七段低饱和光谱出现在顶栏 2px 线、阅读进度条、目录选中点、
  分区序号与品牌弧线里；不做大面积渐变文字或彩色卡片底。
- **进场只发生一次。** 首屏文字按 60–460ms 依次上移，标题用裁切揭示；研究板块的
  光谱下划线保持静态，不随滚动渐显。`prefers-reduced-motion` 下所有内容直接落到终态，
  没有隐藏文字，也没有滚动联动的位移。
- **阅读是主角。** 长文页有顶部阅读进度条、右侧粘性 anchor 目录（二级标题嵌套、
  滚动高亮）、标题悬停锚点、正文字号切换与代码块复制。目录条目与标题 `id` 都写在
  HTML 里，禁用 JS 也能跳转。
- **一套系统。** 1280px 内容宽（12 列网格、24px 栏距）、一套圆角、一种主按钮、
  一种链接下划线、一种卡片。
  所有块贴同一条左右边线，卡片悬停上移 2px，按钮按下回落，箭头移动 3px。

### 主题变量

| 变量     | 亮色               | 暗色               |
| -------- | ------------------ | ------------------ |
| 背景     | `hsl(200 32% 97%)` | `hsl(203 60% 12%)` |
| 次级面   | `hsl(200 28% 94%)` | `hsl(203 48% 17%)` |
| 正文     | `hsl(203 34% 21%)` | `hsl(198 26% 86%)` |
| 次要文字 | `hsl(203 22% 35%)` | `hsl(198 20% 72%)` |
| 弱化文字 | `hsl(203 15% 44%)` | `hsl(198 16% 60%)` |
| 强调色   | `hsl(196 52% 34%)` | `hsl(190 48% 66%)` |
| 代码底   | `hsl(200 26% 93%)` | `hsl(203 42% 16%)` |

首次进入固定为亮色，主题选择写入 `localStorage`；首屏前的内联脚本先写入
`data-theme` 避免闪白，也支持 `?theme=dark` 直接查看暗色。没有手动选择时，
系统主题发生变化才跟着切换。

| 页面                 | 内容                                               |

| `index.html`         | 首屏、最近更新、知识库四层入口、研究与踩坑         |
| `posts.html`         | 22 篇文章，标签筛选与关键词搜索                    |
| `article.html`       | 长文详情：进度条、粘性目录、字号、代码排版、上下篇 |

## 交互清单

- 亮 / 暗主题切换，持久化并跟随系统偏好
- 首屏一次性进场动画、悬停下划线与卡片微动效
- 长文阅读进度条（顶部 + 目录侧轨 + 百分比）
- anchor 目录：点击跳转、滚动高亮、二级标题嵌套
- 正文标题 hover 显示 `#` 锚点，字号 0.9–1.2 倍可调并持久化
- 代码块一键复制
- 文章列表标签筛选、关键词过滤与结果计数
- 移动端全屏菜单、单列布局、目录降级为顶部横排

```
    │   ├── chrome.css          页头、菜单、页脚、进度条
    │   ├── home.css            首屏、阅读器示意、首页板块
    │   ├── library.css         列表、归档、项目、在用、研究、404
    │   ├── article.css         长文正文、目录、代码、表格
    │   └── responsive.css      平板与窄屏的降级规则

        ├── reading.js          进度、目录高亮、字号、代码复制

```

## 边界

- 文章标题、日期、标签、研究结论与在用清单取自仓库 `content/`；正文以两篇长文
  作为完整排版示例。列表里的链接都指向这两篇示例页，正式落地时换成真实路由。
- 「22 篇文章 / 20 篇归档 / 1 份研究报告 / 3 个项目」是按当前 `content/` 文件数
  写的原型计数；内容增删后需要同步更新文案。
- `content/research/` 的结论依赖当时的机器状态，页面固定标注本机环境依赖与复验
  要求；引用前须在本机复跑命令，不能当通用结论使用。
- 不引入框架、第三方 UI 库、web font 或外部图片；不使用照片，靠真实排版、文章
  阅读器示意与光谱细线承载视觉。
- 正式落地时 `tokens.css` 的变量可迁移到 `app/styles/index.css` 与 UnoCSS theme，
  页面拆成 Nuxt 页面与组件；本原型不参与 `pnpm generate`。
