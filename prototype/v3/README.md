# UI 重构 · 交互原型 v3

把站点当成**个人知识库**来排版的一版原型：除了博文，还展示项目、在用工具、
研究 / 踩坑内容与归档。它不接入 Nuxt 构建，也不改动现有页面，只用来确认视觉方向、
信息层级与阅读交互。

## 运行

原型不加载任何 web font：中文走系统字体，标题走系统衬线，代码走系统等宽。
从仓库根目录起一个静态服务（ES module 需要 http）：

```bash
python3 -m http.server 4173 --directory .
```

打开 <http://localhost:4173/prototype/v3/>。`?theme=dark` 可直接查看暗色。
**全站搜索需要联网**：它调用站点已有的 Algolia 索引，断网时面板会明确提示不可用。

## 设计取向

- **直角、克制。** 所有边框、按钮、卡片、标签、代码块统一 `border-radius: 0`；
  卡片内边距 16px、代码块 12/16px、章节上下 72/48px，尽量把空间还给内容。
- **淡色纸面。** 亮色以 `hsl(200 32% 97%)` 为底，墨色 `hsl(203 34% 21%)`；
  暗色主色固定 `hsl(203 60% 12%)`，字面 `hsl(198 26% 86%)`。两套主题都用有彩底
  与有彩字，没有纯黑纯白大色块，也没有从黑封面翻到白纸的明暗跳变。
- **适配大屏。** 内容宽 `min(100% - 2 * 80px, 1760px)`：1440 屏仍是 1280，
  2560 屏铺到 1760。章节按内容自然高度排列，不再强制每节一屏，避免大片空白。
- **彩虹只做细线。** 顶栏 2px 光谱线、阅读进度条、目录选中点、分区序号和
  陈述句下划线；页头只有文字标记，页脚没有巨大字标。
- **目录是线条缩略图。** 每个 anchor 用一根长短不一的横线表示，层级靠缩进与线长区分；
  收起时把手只露一叠短线，展开后顶部显示当前章节名，悬停某根线即时预览对应标题。
- **进场只发生一次。** 首屏整体与文字按 60–460ms 依次上移，标题裁切揭示；
  `prefers-reduced-motion` 下直接落到终态。首屏前的内联脚本在**所有样式表之前**
  写好主题、`m-enter` 与正文字号，`body` 不做颜色过渡，因此没有加载时的闪动或
  字号跳动。

### 主题变量

| 变量   | 亮色               | 暗色               |
| ------ | ------------------ | ------------------ |
| 背景   | `hsl(200 32% 97%)` | `hsl(203 60% 12%)` |
| 次级面 | `hsl(200 28% 94%)` | `hsl(203 48% 17%)` |
| 正文   | `hsl(203 34% 21%)` | `hsl(198 26% 86%)` |
| 强调色 | `hsl(196 52% 34%)` | `hsl(190 48% 66%)` |
| 代码底 | `hsl(200 26% 93%)` | `hsl(203 42% 16%)` |

代码高亮的 token 配色另有一套低饱和变量（`--tok-comment` / `--tok-keyword` /
`--tok-string` / `--tok-number` / `--tok-function` / `--tok-constant` /
`--tok-variable`），亮暗各一份，由 `highlight.css` 定义。

主题选择写入 `localStorage`，未手动选择时系统主题变化才跟着切换；字号持久化后
由首屏前脚本恢复，避免正文重排。

## 交互清单

- 亮 / 暗主题切换，持久化并跟随系统偏好
- 首屏一次性进场动画、悬停下划线与卡片微动效
- **全站 Algolia 搜索**：页头按钮、列表页按钮或 `⌘K` / `Ctrl K` / `/` 打开，
  `↑↓` 选择、`↵` 打开、`Esc` 关闭；结果来自 `rainbowatcher` 索引
- **默认收起的线条目录**：沿视口右缘只露 28px 的短线把手，hover、聚焦或点击把手
  才展开；线条缩略图 + 当前章节名，不占布局列，正文宽度提升到 960px
- 长文阅读进度条（顶部 + 百分比）、标题悬停锚点、字号 0.9–1.2 倍可调并持久化
- 代码块语法着色（字符串、注释、数字、关键字、函数、shell 变量）与一键复制
- 文章列表标签筛选与结果计数
- 移动端全屏菜单、单列布局

## 边界

- 文章标题、日期、标签、研究结论与在用清单取自仓库 `content/`；正文以两篇长文
  作为完整排版示例。列表链接与 Algolia 命中都指向这两篇示例页，正式落地时换成真实路由。
- 「22 篇文章 / 20 篇归档 / 1 份研究报告 / 3 个项目」按当前 `content/` 文件数写，
  内容增删后需同步更新文案。
- Algolia 的 `appId` / `apiKey` / `indexName` 取自 `siteConfig.ts` 的 `docSearch`，
  是公开搜索凭据；客户端从 jsDelivr 按需加载 `algoliasearch-lite`，首次查询可能因
  DNS 重试稍慢。命中结果按 URL 前缀映射到原型对应页面，不代表线上真实路由。
- `content/research/` 的结论依赖当时的机器状态，页面固定标注本机环境依赖与复验
  要求；引用前须在本机复跑命令，不能当通用结论使用。
- 不引入框架、第三方 UI 库、web font 或外部图片；不使用照片，靠真实排版、文章
  阅读器示意与光谱细线承载视觉。
- 章节改为内容自然高度后，tasteskill 的「一屏一节」检查会报
  `screen-short` / `neighbour` / `hero-fold`；这是按「不留过多空白」刻意取舍，
  不是布局错误。
- 正式落地时 `tokens.css` 的变量可迁移到 `app/styles/index.css` 与 UnoCSS theme，
  页面拆成 Nuxt 页面与组件；本原型不参与 `pnpm generate`。
