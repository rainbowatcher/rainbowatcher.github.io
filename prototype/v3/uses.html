编辑器

VS Code日常写 TS / Vue 的主力编辑器。
One Dark Pro用了很多年的一套配色。
FiraCode连字开启后的等宽字体。
0xProto终端里换着用的等宽字体。

浏览器扩展

Refined GitHub给 GitHub 页面补上常用操作。
Vimium C键盘操作浏览器标签与链接。
Immersive Translate对照阅读外文文档。

应用

Raycast启动器、剪贴板与窗口管理。
AlacrittyGPU 加速的终端模拟器。
LocalSend局域网里传文件，不经过云。

硬件

MacBook Pro 13 英寸2020 款，16GB 内存。
Filco Majestouch Convertible 2TKL 布局，Cherry MX 红轴。
Logitech G304无线鼠标，出门带着走。

命令行

zsh默认 shell，配置在 scripts 仓库。
pnpm包管理器，也用来管 monorepo。
ni按项目自动选包管理器。
taze批量检查依赖的可用更新。
