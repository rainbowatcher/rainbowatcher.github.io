# UI 重构 · 交互原型 v1

这是站点 UI 重构的第一版可交互原型。它不接入 Nuxt 构建，也不改动现有页面，
用于先确认视觉方向、信息层级与交互方式。

## 运行

原型会加载 `app/public/fonts` 下的本地字体，因此需要从仓库根目录起一个静态服务：

```bash
python3 -m http.server 4173 --directory .
```

打开 <http://localhost:4173/prototype/>。

也可以直接打开 `prototype/index.html`，但浏览器会拦截 ES module 与部分字体，
推荐用上面的本地服务。

## 这一版的设计目标

1. **阅读优先。** 正文 17px / 1.9 行高，正文列 700px（约 40 个汉字）；
   标题、摘要、元信息之间用字号、字重与留白拉开层级。
2. **对比度达标。** 正文对纸底 15.55:1（AAA），次要文字 9.18:1（AAA），
   元信息 5.66:1（AA），强调色 6.02:1（AA）。所有正文配色至少 AA。
3. **布局有骨架。** 统一 1160px 内容宽度；列表用「日期—标题—主题—箭头」四列，
   文章页是「正文 + 右侧粘性目录」，移动端降级为可折叠目录。
4. **颜色有节制。** 暖纸底 + 墨色字 + 单一青绿强调色；彩虹只作为 2px 品牌线
   与环形标记出现，不再用大面积渐变文字。

### 配色与实测对比度

| 配色对            | 亮色    | 暗色    | 目标 |
| ----------------- | ------- | ------- | ---- |
| 正文 / 背景       | 15.55:1 | 16.03:1 | AAA  |
| 次要文字 / 背景   | 9.18:1  | 11.66:1 | AAA  |
| 元信息 / 背景     | 5.66:1  | 7.73:1  | AA   |
| 强调链接 / 背景   | 6.02:1  | 10.75:1 | AA   |
| 强调色 / 强调底   | 5.43:1  | 8.05:1  | AA   |
| 按钮文字 / 按钮底 | 6.40:1  | 10.81:1 | AA   |
| 代码 / 代码底     | 13.56:1 | 15.06:1 | AAA  |

数值在页面内实时计算：页脚「设计说明 / 对比度自检」，或右下角的 `Aa`。

## 页面

- `/`：自我介绍、站点速览、最近更新、主题入口、联系方式
- `/posts`：文章列表，支持主题筛选、关键词过滤与分页
- `/posts/:slug`：文章详情，含目录、阅读进度、字号切换、代码复制、上下篇
- `/archives`：按年份分组的归档
- `/uses`：按场景分组的工具与硬件清单
- `/projects`：项目卡片
- `/research`：研究分区与报告详情
- 404：无效地址

## 可交互的地方

- 亮 / 暗主题切换，写入 `localStorage`，首屏前内联脚本避免闪白
- `⌘K` / `Ctrl K` / `/` 打开全局搜索，`↑↓` 选择、`↵` 打开、`Esc` 关闭
- 文章列表的关键词搜索、主题筛选与分页（页码写回 URL）
- 文章页目录点击与滚动高亮、阅读进度条、正文字号切换
- 代码块一键复制
- 移动端全屏菜单
- 「设计说明 / 对比度」面板实时显示当前主题的 WCAG 比值

```

├── README.md
└── assets/
    ├── css/
    │   ├── tokens.css      颜色、字体、圆角、间距变量（含暗色）
    │   ├── base.css        重置、排版、按钮、标签、焦点态
    │   ├── chrome.css      页面骨架、顶部导航、页脚
    │   ├── overlays.css    搜索面板、说明/对比度面板
    │   ├── drawer.css      移动端菜单、原型工具条、Toast
    │   ├── views-home.css  首页
    │   ├── views-pages.css 页面头、列表、归档、404
    │   ├── views-uses.css / views-projects.css / views-research.css
    │   ├── views-responsive.css  各页面的窄屏规则
    │   ├── article.css     文章头、正文、代码、表格
    │   ├── article-rail.css  目录、字号、文末、研究提示
    │   └── article-responsive.css
    └── js/
        ├── app.js          hash 路由、页面挂载、全局交互
        ├── data.js         文章 / 研究 / 项目 / 在用数据
        ├── search.js       搜索索引与键盘操作
        ├── theme.js        主题初始化与持久化
        ├── contrast.js     WCAG 对比度计算
        ├── utils.js        日期、转义、列表行等纯函数
        ├── icons.js        内联 SVG 图标
        └── views/          每个页面一个视图模块
```

## 边界

- 内容是原型数据：文章标题与列表来自 `content/`，正文只有少数几篇是完整的，
  其余为演示排版生成的占位段落；项目与「在用」页有示例数据。
- 原型使用 hash 路由与原生 JS，不引入框架或第三方 UI 库。
- 正式落地时，`views/*.js` 会拆成 Nuxt 页面与组件，`tokens.css` 的变量可直接
  迁移到 `app/styles/index.css` 与 UnoCSS theme。
- 原站的自定义书法字体（鸿雷行书）没有用在正文里；如果希望保留品牌感，
  建议只用在品牌字或大字号装饰，不用于正文与导航。
