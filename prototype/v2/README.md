# UI 重构 · 交互原型 v2

在 v1 的基础上重排版：更大的字、更明确的色块与更少的界面零件。它同样不接入
Nuxt 构建，不改动现有页面，用于先确认视觉方向与交互方式。

## 运行

不加载任何 web font：中文走系统字体，代码走系统等宽。从仓库根目录起一个静态服务：

```bash
python3 -m http.server 4173 --directory .
```

打开 <http://localhost:4173/prototype/v2/>。

## 与 v1 的主要差异

1. **浅色主题不再有黑封面。** 封面与顶栏同为暖米纸面，避免从大块黑翻到亮纸时
   的明暗跳变；深色只留在页脚、目录、代码块与浮层等小面积区域。
2. **单一暖色强调。** 琥珀 `#d9a54a` 只做填充与选中态；纸面上的强调文字用更深的
   `#7f5610` 保证 AA，深色面上的强调文字用 `#e3b45f`。
3. **纸面与深面分变量。** `tokens.css` 里分别提供纸面、顶栏、封面、深色面的强调色
   与中性色，靠变量继承切换，业务规则里仍只写 `var(--accent)`。
4. **字体全部系统化。** 不写 `@font-face`；中文为宋体 / 苹方 / 微软雅黑等系统回退，
   代码为 `ui-monospace`。

## 页面

首页、文章列表、文章详情、归档、在用、项目、研究、404，与 v1 一致；差异在版式与
色彩，交互（搜索、主题、目录、代码复制、移动端菜单）沿用同一套。

```
    ├── css/
    │   ├── tokens.css      颜色、字体、尺度变量；纸面/封面/深面三套强调色

    │   ├── chrome.css      顶栏、品牌光谱、页脚
    │   ├── home.css        封面与首页条目
    │   ├── home-sections.css   照片带、主题带、关于区
    │   ├── home-responsive.css 首页窄屏
    │   ├── pages.css       页面头、列表、归档、404
    │   ├── article.css     文章头、正文、代码、表格
    │   ├── article-rail.css    目录、字号、文末
    │   ├── article-responsive.css
    │   ├── library.css     在用 / 项目 / 研究共用版式
    │   └── overlays.css    搜索、移动端菜单、设计说明浮层

```

## 边界

- 内容是原型数据，与 v1 相同；正文只有少数几篇完整。
- 不引入框架、第三方 UI 库或第三方字体。
- 正式落地时把 `views/*.js` 拆成 Nuxt 页面与组件，`tokens.css` 的变量可直接
  迁移到 `app/styles/index.css` 与 UnoCSS theme。
