设计说明与对比度

这一版把界面收成三件事：更大的字、更暖的纸、更少的颜色。浅色主题的封面与顶栏同为纸面，不再黑白对撞；正文对纸底 11.9:1，所有正文配色至少 AA。字体只用系统字，不加载任何 web font。

字号：正文 17px / 文章 17.5px；显示字：宋体；界面字：系统无衬线；代码：系统等宽。
