## 要点

- 「线路质量」= 物理海缆 + 骨干网路由 + 回程方向，回程比去程更影响体验。
- 同一家运营商分公众网（163/169）与精品网（CN2、9929）两级，价格与质量差距大。
- 判断走没走 CN2 看 traceroute 里的 `59.43.x.x` 特征段。

## 机制

访问境外站点的路径分三层：物理海缆（如 TPE、NCP）决定带宽上限；骨干网运营商决定路由与拥塞；接入产品（普通带宽、CN2 GT/GIA、BGP、专线）是前两者的商业包装。日常说的「线路」实质是骨干路由 + 回程优化：机房发给用户的回包走哪条骨干，直接决定延迟与抖动，很多低价 VPS 去程走 CN2、回程走 163，属于半优化。

## 规则与取值

| 线路      | 运营商 / AS  | 定位     | 特征                         |
| --------- | ------------ | -------- | ---------------------------- |
| 163 骨干  | 电信 AS4134  | 公众网   | 便宜量大，高峰期拥堵丢包     |
| CN2 GT    | 电信 AS4809  | 半优化   | 省际走 163，出境后上 CN2     |
| CN2 GIA   | 电信 AS4809  | 全程优化 | 双向专属通道，延迟最低、最贵 |
| 169 骨干  | 联通 AS4837  | 公众网   | 性价比高，高峰比 163 稍稳    |
| AS9929    | 联通 CUG     | 精品网   | 联通版 CN2 级优化            |
| CMI       | 移动 AS58453 | 国际出口 | 海缆资源多，对移动用户友好   |
| IPLC/IEPL | 各家         | 物理专线 | 不走公网，稳定但贵           |

参考延迟（依据：常见测速报告，未验证）：上海→美西 CN2 GIA 约 130–150ms，163 公众网约 180–220ms 且晚高峰可能高丢包。

## 示例

判断回程是否走 CN2 骨干：

```bash
mtr -rw <机房IP>
# 出现 59.43.x.x 段 → 走 CN2 骨干
```

正例：全程 59.43.x.x = GIA 级；反例：去程 59.43.x.x、回程 202.97.x.x（163 骨干）= 半优化。晚 8–11 点复测丢包：<1% 为优，>5% 高峰基本不可用。

## 边界

- 延迟数值随出口城市、时段与海缆状态波动，上表数字为常见区间而非承诺。
- 香港/日本/新加坡节点还有本地线路（HKBN、NTT、Softbank 等）与大陆优化线路之分，本文只覆盖大陆三大运营商骨干。
